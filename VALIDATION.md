# W3 compatibility validation

The package is an established thin department orchestrator without local bootstrap/doctor/CI scripts. Central Ecosystem v0.5.4 validation supplies manifest/MCP/skills, links, root/payload safety and portable archive checks. Run Node domain tests and `plugin:certify-thin --repo <absolute repo>` from that exact Ecosystem. Certification requires a clean committed candidate. LICENSE must equal the canonical MIT Git blob.

`tests/marketing-routing.test.mjs` tests competent-context requirements, scope/evidence binding, UNKNOWN/stale denial, public/non-person approved content and owner routing. Tests do not qualify a production host, provider or Operator E2E. Historic v0.5.0 remains immutable; proposed v0.5.1 changes department eligibility only.
