# WOIA Marketing Status

Report only durable Project/Task state:

- objective and current Task;
- OPEA-H profile/current phase;
- selected Marketing capabilities/providers;
- outputs/evidence already established;
- external effects already attempted/confirmed/unknown;
- blockers and exact recovery;
- pending Human Review/authorization;
- next meaningful action.

Do not rerun provider inventory, rebuild custom roles, or rescan all Project state just to answer status.
