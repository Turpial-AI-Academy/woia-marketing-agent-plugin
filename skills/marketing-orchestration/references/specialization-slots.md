# Methodology extension slots

`scripts/evaluate-methodology.mjs` exports `evaluateMethodology(request, trustedHost)` and four named slots:

| Slot | Generic ownership |
| --- | --- |
| source-resolution | Current accepted evidence and source-map references |
| content-domain-validation | Scope, approved content and source constraints |
| channel-effect-policy | Public organic publication and owned handoffs |
| outcome-evidence | Provider observations, receipts and separate acceptance |

A host-admitted delta may ADD, SPECIALIZE or NARROW those slots using the exact Core composition snapshot. The base evaluates its generic request first. The delta consumes that result and independently resolved accepted descriptors; request fields never select modules, roots or domain policy.

The result binds the complete request digest, exact base version, Task/scope, source-map revision, binding revision and snapshot. `METHOD_ELIGIBLE` only permits continued coordination. It never grants authority, writes facts or dispatches an adapter. Missing or stale specialization bindings stop that specialized Task.
